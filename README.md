# Database Backup Utility

Database Backup Utility is a command-line interface tool for backing up and restoring databases. This project currently supports MongoDB and Redis.

## Project URL

https://roadmap.sh/projects/database-backup-utility

## Features

- MongoDB backup
- MongoDB restore
- Redis backup
- Redis restore
- Local backup storage
- Backup logging
- Command-line interface

## Tech Stack

- Go
- MongoDB Database Tools
- Redis CLI
- File System
- Logging
